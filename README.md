# wishbusterz-web

The website for **Wishbusterz**.

## The idea

Someone has a wish. We find out whether AI can solve it. If it can, we
build it — and open-source it so anyone can use it and play with it.

## Where the channel lives

- YouTube — the builds
- Twitch — live streams
- Facebook — planned

## What the site needs (v1)

- **About** — who we are and what the channel is for
- **Follow / subscribe** — links out to every platform
- **Projects** — every solved wish, with the open-source code
- **Wiki** — how-to prompts and ideas people can take and reuse

## Status

Design phase. 21 visual directions mocked up and under review; no
style chosen yet, so nothing is built.
