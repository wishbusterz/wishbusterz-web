How a wish becomes code

Three steps, in this order, every time.

  1. 01

    You wish

    Anyone sends in something they want to exist. No technical detail needed — describe it like you'd describe it to a friend.

  2. 02

    We test it

    Live on stream, we find out whether today's AI can genuinely do it. Plenty of wishes get busted here, and that episode still goes out.

  3. 03

    You keep it

    Anything that works ships to GitHub under an open licence, with a wiki page explaining the prompts and the wiring.

About

Wishbusterz started from a simple, slightly annoying question: people keep saying AI can do anything, so — can it do this?

We take one wish at a time and actually try. The building happens live on Twitch, the edited version lands on YouTube, and everything that survives contact with reality gets open-sourced so you can run it yourself.

Half the wishes get busted. We publish those too. An honest failure is more useful than a demo that only works once.
